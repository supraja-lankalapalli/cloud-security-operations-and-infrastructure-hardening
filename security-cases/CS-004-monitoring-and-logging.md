# CS-004 - Monitoring and Logging

## Objective

Verify that AWS management activity is recorded for monitoring and security investigations.

## Problem

Without logging, it is difficult to determine who performed actions in an AWS environment or investigate security-related events.

## Environment

- AWS CloudTrail
- AWS Management Console

## What I Did

- Opened AWS CloudTrail.
- Reviewed the Event History.
- Verified that management events were being recorded.
- Confirmed activities such as console logins, EC2 operations, and security group changes were captured.

## Security Improvements

- Verified centralized logging of AWS management events.
- Confirmed that account activity is available for auditing and investigation.
- Improved visibility into administrative actions performed within the AWS environment.

## Result

CloudTrail successfully records AWS management activity, providing visibility that supports monitoring, auditing, and future security investigations.

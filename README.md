# Cloud Security Operations & Infrastructure Hardening

## Overview

This project simulates the responsibilities of a Cloud Security Engineer responsible for securing, monitoring, investigating, and improving an AWS environment.

The objective is to identify security risks, investigate incidents, implement remediation, and continuously strengthen the security posture using AWS native security services and security best practices.

## Project Focus

- Infrastructure Hardening
- Threat Detection
- Incident Response
- Security Monitoring
- Security Validation
- Continuous Security Improvements
